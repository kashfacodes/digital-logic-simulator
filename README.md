# Digital Logic Simulator

An interactive digital logic simulator built using Python and Tkinter.

## Features

- Seven logic gates: AND, OR, NOT, NAND, NOR, XOR, and XNOR
- Interactive binary input controls
- Half adder and full adder calculations
- Live output display
- Graphical interface built with Tkinter
- Simplified circuit diagrams that update with the selected operation

## Technologies Used

- Python
- Tkinter
- Digital Logic Design

## How to Run

1. Install Python 3 if it is not already installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   ```bash
   python digital_logic_simulator.py
   ```
